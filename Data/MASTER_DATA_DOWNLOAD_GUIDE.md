## What Each Dataset Proves in BHU LOKA

| Dataset | Scientific Role | What It Enables |
|:---|:---|:---|
| Sentinel-1 SAR (Sep 2019) | Ground truth flood mapping | Real flood extent verification for Rajendra Nagar, Kankarbagh |
| Sentinel-2 MSI (May 2019) | Land cover before flood | Impervious fraction — real, not simulated |
| SRTM DEM | Terrain analysis | TWI, slope, depression sinks |
| IMD Rainfall | Forcing variable | 340mm event quantification and downscaling |
| MODIS LST | Thermodynamic coupling | Real temperature before flood — tests 40°C soil desiccation hypothesis |
| WorldPop | Exposure (E) in Risk equation | Real human exposure counts per ward |

## After All Downloads Are Complete

Run the processing pipeline in this order:

```
Step 1: python scripts/03_process_sar_inundation.py    -> Real flood raster
Step 2: python scripts/04_compute_terrain_indices.py   -> TWI, slope
Step 3: python scripts/05_compute_lulc_indices.py      -> NDVI, NDBI, impervious
Step 4: python scripts/06_assemble_ml_dataset.py       -> Feature matrix CSV
Step 5: python scripts/07_train_spatial_model.py       -> REAL R², RMSE, SHAP values
Step 6: python scripts/08_generate_figures.py          -> Publication figures from real data
```

Only after Step 5 completes with real data can we report any R² or RMSE values in the paper.
